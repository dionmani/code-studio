Run Code Studio on this PC

A local copy runs directly on Windows, using your own Python, drivers, databases and folders. That helps with projects that need Windows-only things (SQL Server/ODBC, a Windows .venv) which this server's Linux container doesn't have.

Install (Windows 10/11)

  1. Download the package. It is version {{ build.version }} ({{ build.build }}), the same code this server runs.
  2. Right-click the zip, choose Extract All…, then open the extracted folder.
  3. Double-click Install Code Studio.cmd. If Windows shows “Windows protected your PC”, click More info → Run anyway (the installer isn't code-signed).
  4. Answer the prompts: an admin password for the local copy, your projects folder and, optionally, the AI agent tools.
  5. Start it from the Code Studio shortcut on your desktop or in the Start Menu.
Download for Windows

What gets installed

  • Python 3.12, via winget, if it isn't installed already.
  • Code Studio in %LOCALAPPDATA%\Programs\CodeStudio: app\ (program, replaced on update), venv\, data\ (database and settings, kept) and config.json (kept).
  • Optional: Node.js plus the Claude Code and Codex command-line tools for AI agents.

Keeping it up to date

Your local copy checks this server each time it starts and offers the update when this server has a newer build. It also shows Update available in its top bar. Updating downloads the new package from here and keeps your local sign-in, projects and settings.

Good to know

  • The local copy is separate: its own admin sign-in, project list and agent logins. Nothing syncs with this server.
  • The package contains a download token tied to your account, used only to fetch updates. Don't share the zip.
