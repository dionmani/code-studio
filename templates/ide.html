Project checks 

            
Settings for agents working on this project, and the commands a
              Verify step runs. A Verify step is a profile whose agent is “Checks”: it runs these commands
              (not an AI) and passes the real results to the next steps.

            
Open a project first.

            

              

                
                
                
One per line, run in order in a throwaway copy of the agents' work (what they write is
                  discarded). All run even if one fails. Plain commands only: no pipes, redirects or shells.

              

              

                
                
                
NAME=value lines, set for every agent and check command. Point your settings at a
                  local test database here. Database settings (DATABASE_URL, DB_*, PG*, …), URLs with passwords, and
                  secret-looking variables are always removed and can't be set.

Line endings (this project)

        

          

            
          

          

        

        
Repositories cloned on Windows usually have CRLF line endings in the files while Git stores
          LF (Git's core.autocrlf). Without the matching setting every file looks modified. Code Studio applies
          this in memory only and does not change the repository's config.
